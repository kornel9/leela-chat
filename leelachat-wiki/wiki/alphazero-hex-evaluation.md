# Evaluation Beyond Task Performance: Analyzing Concepts in AlphaZero in Hex

**Summary**: Probing classifiers and behavioral tests applied to AlphaZero in Hex show that MCTS discovers game concepts before the neural network encodes them, with short-term end-game concepts residing in upper layers and long-term planning concepts in middle layers.

**Sources**: Evaluation Beyond Task Performance AlphaZero in HEX.pdf

**Last updated**: 2026-06-02

---

## Citation
Lovering, Forde, Konidaris, Pavlick, Littman. "Evaluation Beyond Task Performance: Analyzing Concepts in AlphaZero in Hex." NeurIPS 2022.

## Contribution
The paper adapts two NLP evaluation techniques — probing classifiers and behavioral tests — to analyze how AlphaZero learns and uses identifiable game concepts in Hex. Nine Hex concepts are studied across 21 training checkpoints and all network layers. The central finding is that MCTS behaviorally uses concepts before the neural network encodes them, and that those representations are later absorbed into the policy network as it learns to imitate MCTS logits. The dual-method design (probing + behavioral tests) establishes that encoding a concept in activations is not sufficient evidence that the agent uses it causally. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf)

## Method
Linear probing classifiers are trained over each layer of AlphaZero's network body separately. Concept selectivity — probe accuracy minus shuffled-board control accuracy, following Hewitt and Liang 2019 — is the primary probing metric; N=2500 boards per concept are generated by translating minimal templates across empty boards with random enemy pieces added. Behavioral tests construct forced-win boards (N=100 per concept) where playing the concept's key moves guarantees a win; pass rate is measured for both MCTS and the policy network across all 21 training checkpoints. Cell embeddings from the first layer are extracted and dot-product nearest-neighbor NDCG is used to probe implicit board-structure learning. All experiments use the top-performing Jones (2021) Hex agent on a 9×9 board. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf)

## Key findings
- MCTS discovers concepts before the neural network learns to encode them: behavioral test improvements precede probing accuracy improvements, with both converging near end of training. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, Abstract, §4.3, Fig. 6)
- Short-term end-game concepts are best represented in the final (upper) layers of the network; long-term concepts are best represented in the middle layers. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, Abstract, §4.2, Fig. 4b)
- AlphaZero never fully masters negative concepts (dead and captured cells): even at the end of training it plays wasted moves in ~25% of behavioral tests involving dead cells. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, §4.1, Fig. 5b)
- AZ's first-layer cell embeddings implicitly learn Hex's board neighborhood structure (nearest-neighbor NDCG improves through training), but this structural learning co-develops with concept learning rather than preceding it. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, §4.4, Fig. 7, Fig. 6)
- Probing performance alone is insufficient: a concept may be encoded in activations but not causally used; behavioral tests are required as a complementary measure to establish whether encoded representations translate into action. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, §1, §3.4)
- Concept learning does not follow an obvious order or curriculum; concepts of differing complexity develop in parallel across training checkpoints. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, §4.3, Fig. 6)
- The same layerwise short-term/long-term pattern found in Hex appears informally in McGrath et al.'s chess results: 'in check' (short-term) is best represented in higher layers and 'material imbalance' (long-term) in lower layers. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf, §4.2)

## Relevance to Leela Chat
This paper directly informs **Phase 3 (linear concept probes)** by providing a replication-ready methodology: probe per layer with shuffled-board selectivity controls (Hewitt and Liang 2019), N=2500 boards per concept, and behavioral pass-rate as a complementary check. The finding that probing alone is insufficient — a concept may be encoded but not causally used — argues for pairing each Leela Chat concept probe (AUC metric) with a behavioral test or targeted position set that verifies the probe fires on positions where Lc0 actually uses the concept. This constraint belongs in the **extractor layer**: a probe extractor should not report a concept as active unless a corresponding behavioral check also passes. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf)

The short-term/long-term layer-depth finding (confirmed across Hex and informally in chess by McGrath et al.) gives a prior for where to look in BT4's 15-layer body: tactical short-horizon features in upper layers, strategic long-horizon features in middle layers. This should guide layer selection when training probes in Phase 3 and when deciding which residual-stream layers to hook for feature extraction in Phase 4. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf)

The finding that MCTS discovers concepts before the network encodes them is directly relevant to **Phase 2 (MCTS integration)**: MCTS visit-share signals may capture strategic information that the network's [[residual-stream]] does not yet encode at the queried position, suggesting MCTS-derived features extracted in the `mcts` handler are not redundant with network probes from the `what_is_leela_seeing` handler. The two signal sources are complementary inputs to the **translator layer's** findings JSON. (source: Evaluation Beyond Task Performance AlphaZero in HEX.pdf)
