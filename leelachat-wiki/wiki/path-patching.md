# Path patching

**Summary**: Path patching is a causal-intervention technique that localizes a neural network's behavior to specific directed paths through its computational graph (not just to which nodes are present), which for Lc0/BT4 means isolating exactly which residual-stream and attention-head interactions carry a decisive evaluation or policy signal for a given position.

**Sources**: Localizing Model Behavior with Path Patching.pdf, How to Use and Interpret Activation Patching.pdf, Towards Automated Circuit Discovery.pdf

**Last updated**: 2026-06-02

---

## What it is
Path patching generalizes [[activation-patching]] by replacing "unimportant" paths in the computational graph with values from a counterfactual input while holding "important" paths at the reference input, then measuring how much behavior remains unexplained (source: Localizing Model Behavior with Path Patching.pdf, §2.3, Eq. 1). It is strictly more expressive than node-level ablation because paths capture directed interactions between components, not just which nodes are present (source: Localizing Model Behavior with Path Patching.pdf, §1 / §2.1). This matters for Lc0/BT4 because answering "why is this move wrong" requires distinguishing direct composition (A→C) from mediation (A→B→C), which plain component patching cannot do (source: How to Use and Interpret Activation Patching.pdf, §2.2). The result is a faithful, sparse circuit explanation rather than an ad-hoc qualitative one.

## In the literature
- **Localizing Model Behavior with Path Patching** (Goldowsky-Dill et al., 2023) introduces the formalism: a "Treeify" transformation duplicates shared subtrees so each path can receive an independent counterfactual, and the Average Unexplained Effect (AUE) scores a localization hypothesis, where AUE=0 means the hypothesis fully explains the behavior on the tested distribution (source: Localizing Model Behavior with Path Patching.pdf, §2.4, Fig. 3; §2.3, Eq. 1). Applied to induction heads, a sparse 15-path hypothesis explains only 28.2% of behavior, but iterative refinement reaches 73.5% — a 45.3% absolute improvement (source: Localizing Model Behavior with Path Patching.pdf, §3.5, Table 3). On GPT-2 small, including 8 of 144 heads recovers 98.0% of the loss on a number-continuation task, and path patching implicates fewer heads than causal tracing because the counterfactual stays more on-distribution (source: Localizing Model Behavior with Path Patching.pdf, Fig. 11; §4). A key caveat: AUE measures sufficiency, not completeness, so a low AUE does not prove minority paths are truly absent (source: Localizing Model Behavior with Path Patching.pdf, §7.1). See [[localizing-model-behavior-path-patching]].
- **How to Use and Interpret Activation Patching** (Heimersheim & Nanda, 2024) positions path patching as the tool that distinguishes direct composition (A→C) from mediation (A→B→C) or amplification, which standard component patching cannot differentiate (source: How to Use and Interpret Activation Patching.pdf, §2.2). It frames path patching as the finest level of a granularity ladder (residual stream → MLP/attention-head outputs → neurons → SAE features → path patching) and recommends logit difference as the primary exploratory metric because the residual stream adds to logits linearly (source: How to Use and Interpret Activation Patching.pdf, §2.2; §4.1, §5). It also warns that backup/Hydra-effect components compensate for ablated parts at roughly 0.7× of the original boost, making original components appear ~0.3× less important (source: How to Use and Interpret Activation Patching.pdf, §3.2). See [[activation-patching-guide]].
- **Towards Automated Circuit Discovery** (Conmy et al., 2023) automates the manual iteration that path patching otherwise requires: ACDC greedily prunes edges from a residual-stream DAG of attention heads and MLPs whenever deleting an edge raises KL divergence by less than threshold τ (source: Towards Automated Circuit Discovery.pdf, Abstract). On GPT-2 Small's Greater-Than circuit it rediscovered all 5/5 component types and selected just 68 of 32,000 edges, all matching prior manual work, with zero false positives (source: Towards Automated Circuit Discovery.pdf, Abstract). It argues KL divergence is more robust than logit-difference metrics, which can cause unstable pruning when the subgraph's logit difference exceeds the model's (source: Towards Automated Circuit Discovery.pdf, §C.2, Appendix C) — a partial tension with the activation-patching guide's exploratory recommendation of logit difference. Both ACDC and the guide flag the same blind spot: greedy/KL-driven methods systematically miss "negative" components that actively harm task performance (source: Towards Automated Circuit Discovery.pdf, §4.1). See [[automated-circuit-discovery]].

## Relevance to Leela Chat
Path patching is the foundational technique for Phase 6 (differential and counterfactual analysis): the `why_is_my_move_wrong` handler needs to isolate which residual-stream paths carry the decisive evaluation difference between the user's move and Leela's top move, and the Treeify + AUE framework gives a quantitative faithfulness criterion for the resulting circuit (source: Localizing Model Behavior with Path Patching.pdf, §2.4, Fig. 3; §2.3, Eq. 1). Across the pipeline, an extractor runs the patching experiment and returns AUE plus the implicated paths as numbers, the handler assembles them, and the translator narrates the circuit — while the validator must surface that AUE measures sufficiency not completeness so the prose never over-claims a complete circuit (source: Localizing Model Behavior with Path Patching.pdf, §7.1). The ACDC workflow (define behavior metric → specify DAG granularity → patch to isolate subgraph) extends naturally into Phase 7 reasoning-pathway extraction over BT4's policy circuits (source: Towards Automated Circuit Discovery.pdf, Abstract). Because all three papers experiment on GPT-2/toy transformers, applicability to BT4's smolgen-modified attention must be verified before relying on the Treeify decomposition (source: Localizing Model Behavior with Path Patching.pdf, §4; Towards Automated Circuit Discovery.pdf, §4.1).
